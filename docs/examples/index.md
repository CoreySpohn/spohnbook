# Examples

Each example runs through more than one library and is executed when this site
is built. The code shown is the code that ran.

Each page opens with its purpose, its model restrictions, the kind of evidence it
provides, its data sources and the convention profile it applies, before any
code. A page that executes shows that its composition runs with the recorded
versions; it does not show that its results are scientifically correct, and
several pages run across recorded [limitations](../evidence/limitations.md).
Checks inside a page are enforced only where an independent expected value or a
physical bound exists. The [photon-to-electron reference case](photon-to-electron-reference.md)
is the one page bound to an evidence case.
